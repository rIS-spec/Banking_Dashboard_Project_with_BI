# Banking Dashboard Project with BI

An **end-to-end banking analytics project** — from raw transaction data processing in Python/Jupyter to an interactive Business Intelligence dashboard for financial insights.

---

## Project overview

This project analyses banking transaction data to surface insights about customer behaviour, loan performance, transaction patterns, and branch-level metrics — delivered as a fully interactive BI dashboard.

---

## Pipeline overview

```
Raw banking data
      ↓
Data cleaning & EDA (Python / Jupyter Notebook)
      ↓
Feature engineering & aggregation
      ↓
BI Dashboard (Power BI / Tableau)
      ↓
Business insights & recommendations
```

---

## Key analyses

- Customer segmentation by transaction volume and account type
- Loan approval and default rate analysis
- Branch-wise performance comparison
- Transaction trend analysis (daily, monthly, seasonal)
- High-value customer identification

---
